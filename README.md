# 📝 作业小管家

帮小朋友按科目记录每天的家庭作业，再也不怕忘记啦！

## ✨ 功能

- **📝 作业记录**：按科目（语文/数学/英语…）添加作业，可写备注、设置截止日期；完成后打勾，还有彩带庆祝 🎉
- **🎤 语音输入**：添加作业时点麦克风按钮直接说话，APK 用安卓系统语音识别（离线可用），网页版用浏览器语音识别
- **📚 知识库**：内置初中 7 科知识点思维导图（数学/语文/英语/物理/化学/历史/政治，共 195 页），每页生成提纲目录，点选即看，支持缩放翻页
- **📅 逾期提醒**：过了截止日期还没完成的作业自动标红，显示"已逾期 N 天"
- **🌟 打卡统计**：每天完成作业后打卡，查看今日/本周完成情况、最近 7 天图表、连续打卡天数
- **⏰ 番茄钟**：内置专注计时器，写作业更高效
- **⚙️ 设置**：科目可增删、自定义称呼、导出/导入备份、清空已完成
- **📴 离线可用**：网页版可安装到手机桌面；也可打包成安卓 APK 原生使用

## 📦 交付形态

| 形态 | 说明 |
| --- | --- |
| **安卓 APK** | `作业小管家.apk`，WebView 原生壳，完全离线，装到手机直接用 |
| **网页版 (PWA)** | 双击 `index.html` 即可用；或 `启动服务.ps1` 局域网手机访问；或部署到 GitHub Pages / Netlify |

## 🚀 网页版怎么用

1. **最快**：双击 `index.html`
2. **手机上用**：运行 `启动服务.ps1`（右键 → 以管理员身份运行），手机连同一 WiFi 访问屏幕显示的地址
3. **装到手机桌面**：手机浏览器打开后 →「添加到主屏幕」

## 📱 安卓 APK

- 直接发送 `作业小管家.apk` 到手机安装（首次需允许"未知来源应用"）
- 改网页代码后重新打包：右键运行 `重新打包.ps1`（需保留本地 `android-build/` 目录，含签名密钥与工具链，该目录不上传 GitHub）

## 🗂️ 文件结构

```
index.html / css/ / js/ / icons/  网页应用
manifest.webmanifest / sw.js      PWA 配置与离线缓存
作业小管家.apk                    安卓安装包
server.js / 启动服务.ps1          本地起服务（手机局域网访问）
重新打包.ps1                      一键重新生成 APK
android-build/                    （本地）构建工具链 + 签名密钥，勿删
```

## 💾 数据

- 数据存在**手机本地**，请定期「设置 → 导出备份」下载 JSON
- 换设备用「导入备份」恢复
